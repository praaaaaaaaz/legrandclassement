3. How We Use Information

  • To publish video content on the @legrandclassement TikTok account

4. Data Sharing

We do not sell, trade, or transfer any data to third parties. Data accessed through TikTok APIs is used solely for operating this service and is never shared with external parties.

5. TikTok API Data

Data obtained through TikTok APIs is subject to TikTok's Privacy Policy in addition to this policy. We comply with all TikTok API Terms of Service and data handling requirements. We only request the minimum scopes necessary for our application to function.

6. Data Security

We implement appropriate technical measures to protect data against unauthorized access, alteration, or destruction. Data is stored on a private server with restricted access. API credentials are stored securely and never exposed publicly.

7. Data Retention

We retain performance analytics data for as long as necessary to improve content quality. You may request deletion of any data related to your account by contacting us.
